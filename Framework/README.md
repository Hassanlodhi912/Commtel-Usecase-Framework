# Commtel Use Case Framework (Excel)

`Commtel_Usecase_Framework.xlsx` is the register of all 581 Commtel SIEM use cases.

- **L1 UC:** kill chain stages and other threat categories.
- **L2 UC:** MITRE ATT&CK tactics under each stage.
- **L3 UC:** every technical use case with its CUC number, MITRE technique, scores, Commtel Status and a link to its document.
- **Results:** overall scores and Commtel progress.

Download the file and open it in Excel. To mark a use case done, set **Commtel Status** to Documented.
